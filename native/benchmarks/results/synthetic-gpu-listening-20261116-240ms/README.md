# 合成双说话人试听：240 ms 档

这三段文件使用 Windows SAPI 合成的两种说话声音，与个人录音无关：Zira 是录入并保留的目标声音，Huihui 是干扰声音。原混音中两人整段 RMS 相等，后处理采用普通 GTCRN 模式，处理块长 240 ms。音频文件不随 Git 仓库分发；这是早期测试记录，不代表当前程序的完整音频路径。

- `01-synthetic-mix.wav`：未处理混音。
- `02-cpu-reference.wav`：正式 Rust CPU 模型处理结果。
- `03-gpu-experimental.wav`：早期 DirectML GPU 提取 + CPU 降噪结果；外层为 Python/SciPy 模拟、双进程 IPC（保留历史测试文件名）。

为便于比较声音，处理结果按目标声音离线对齐，三段采用同一个增益，均截取约 12 秒。因此这些 WAV **不能用来判断真实实时延迟**。它们仅代表一组安静的合成双人混音；音质、漏字与不同环境效果需要真实麦克风/噪声场景另测。`quality.json` 保存该次离线对齐指标和试听文件校验值。
